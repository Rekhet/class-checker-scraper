Setup & Run

Get from a clean checkout to a running server in five steps. The web server and database layer are pure standard library; only crawling needs third-party packages.

Prerequisites

  • Python ≥ 3.9 (developed on 3.14).
  • A package installer — uv (used here) or pip.
  • A browser for Playwright — Chromium, installed once (below). Needed only to mint sugang session cookies for crawling.

Install

  1. Create the virtual environment. 
    python3 -m venv .venv
  2. Install runtime dependencies. With uv: 
    # requests · xlrd · beautifulsoup4 · playwright
VIRTUAL_ENV=.venv uv pip install -e .

# optional extras
VIRTUAL_ENV=.venv uv pip install -e ".[turso]"   # libSQL backend
VIRTUAL_ENV=.venv uv pip install -e ".[speed]"   # lxml (faster HTML parse)
    With plain pip: .venv/bin/pip install -e ..
  3. Install the Chromium browser Playwright drives to mint cookies. 
    .venv/bin/playwright install chromium
  4. Start the server. 
    PORT=8011 .venv/bin/python scraper/server.py
  5. Open the UI at http://127.0.0.1:8011.
💡

The DB schema is created automatically on first connection — no migration step. A fresh DB simply has zero classes until the first crawl.

First crawl

The catalog is empty until you populate it. Two ways:

  • From the UI — open the 관리자 / Admin panel, pick a semester (or 전체 All), press DB 새로고침. Progress streams live.
  • From the CLI — scoped to one term is fastest: 
    .venv/bin/python scraper/crawl.py --years 2026 \
  --terms U000200002U000300001

See Crawling & Data for what each pass does and how long it takes.

Environment variables

All optional — sensible defaults apply. Set them in the shell before launching the server or the crawler.

VariableDefaultPurpose
PORT8000HTTP listen port (loopback only).
ADMIN_TOKENunsetIf set, refresh endpoints require header X-Admin-Token.
DB_BACKENDsqlitesqlite or turso (libSQL).
TURSO_DATABASE_URLunsetlibSQL target: a local file path, file:…, libsql://…, or http://127.0.0.1:8080.
TURSO_AUTH_TOKENunsetAuth token for a remote Turso database.
TURSO_SYNC_PATHunsetLocal replica file for an embedded-replica setup.
CRAWL_YEARS2026Default year scope for server-triggered crawls.
CRAWL_TERMSallDefault term scope (comma-separated cmmnCd).

Run against local Turso

Once migrated (see Database & Turso), point the server at the libSQL file — the only change is the environment:

DB_BACKEND=turso TURSO_DATABASE_URL=data/turso.db \
  PORT=8011 .venv/bin/python scraper/server.py

The status bar then reports DB libsql. With no env set it stays on SQLite (data/classes.db).
