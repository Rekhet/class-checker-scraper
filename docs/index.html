SNU Class Checker

A course-search tool for Seoul National University's sugang catalog: exact per-class timetables, fast filters, and a drag-free temporary timetable — built on a tiny stdlib server with a swappable SQLite / Turso backend.

Python stdlib HTTP SQLite · Turso/libSQL Playwright cookies Vanilla JS UI

This site documents how the system is set up, how the crawl collects and reconciles class data from three SNU sources, the database and backend options, the HTTP API, and how to keep it all running.

How it works

The crawl pulls from three SNU endpoints with different strengths, merges them into one catalog, and serves it to a vanilla-JS frontend.

🗂️

Excel = source of truth

One .xls per term gives the full roster + exact 요일(HH:MM~HH:MM) blocks. Authoritative when present.

🧭

Search fills the gaps

When the Excel timetable hasn't landed (e.g. fall), per-cell search queries recover approximate timing.

⚡

Live counts overlay

Cart & enrolment numbers lag in the Excel, so they are re-polled from the live search HTML.
